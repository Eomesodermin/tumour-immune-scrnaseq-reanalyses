## What this analysis does

Processes the pan-cancer NK reference and examines NKG7 and TLR2 expression, including in renal cell carcinoma.

## Scripts

Run in numeric order from this folder. Each script sets the working directory with `here::here()`, which resolves to this folder via the `.here` marker.

| Script | Title |
|---|---|
| `scripts/01_Processing.Rmd` | Pan_Cancer_scRNAseq_Pre_processing |
| `scripts/02_NKG7_Expression.Rmd` | Pan_Cancer_scRNAseq_NKG7_Expression |
| `scripts/03_DEG_and_imputation.Rmd` | Pan_Cancer_scRNAseq_Pre_processing |
| `scripts/04_NKG7_in_RCC.Rmd` | Pan_Cancer_scRNAseq_NKG7_Expression |
| `scripts/05_TLR2_Expression.Rmd` | 05_TLR2_Expression |


`Setup.R` and `Load_packages.R` hold the shared environment set-up; `Functions/` holds helper functions.

No `renv.lock` is committed; the key packages are `Seurat`, `dplyr`, `ggplot2` and the helper package [`r-utility-functions`](https://github.com/Eomesodermin/r-utility-functions).

## Data

The raw and processed data are not stored in this repository. Download the data from the source above into `data/` (git-ignored) before running the scripts; processed objects are regenerated by the numbered scripts.
