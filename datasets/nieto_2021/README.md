# Nieto et al. (2021)

> Nieto P, Elosua-Bayes M, Trincado JL, et al. A single-cell tumor immune atlas for precision oncology. *Genome Res* 2021.
> DOI: [10.1101/gr.273300.120](https://doi.org/10.1101/gr.273300.120)

| | |
|---|---|
| **Species** | Human |
| **Assay** | Integrated 10x Genomics atlas (>500,000 cells, 13 cancer types) |
| **Biological system** | Pan-cancer tumour-infiltrating immune cells |
| **Data** | [Zenodo 4036019 (Seurat/AnnData objects, ~27 GB)](https://zenodo.org/records/4036019) |

## What this analysis does

Preprocesses the Tumour Immune Cell Atlas and scores a CD226 (DNAM-1) axis signature across immune cell types.

## Scripts

Run in numeric order from this folder. Each script sets the working directory with `here::here()`, which resolves to this folder via the `.here` marker.

| Script | Title |
|---|---|
| `scripts/01_TICAtlas_dataset_preprocessing.Rmd` | TICAtlas_dataset_preprocessing |
| `scripts/03_TICAtlas_CD226_signature.Rmd` | TICAtlas_dataset |


`Setup.R` holds the shared environment set-up.

No `renv.lock` is committed; the key packages are `Seurat`, `dplyr`, `ggplot2` and the helper package [`r-utility-functions`](https://github.com/Eomesodermin/r-utility-functions).

## Data

The raw and processed data are not stored in this repository. Download the data from the source above into `data/` (git-ignored) before running the scripts; processed objects are regenerated by the numbered scripts.
