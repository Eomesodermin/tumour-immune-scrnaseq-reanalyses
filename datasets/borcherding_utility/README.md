## What this analysis does

Processes the uTILity collection (harmonised public tumour-infiltrating lymphocyte data) and examines NKG7 and TLR2 expression, including in renal cell carcinoma.

## Key finding

NKG7 is expressed in CD8 T and NK cells and tracks tightly with the cytotoxic programme (PRF1, GZMA/B/H, GNLY, CTSW) across tumour types; TLR2 is mainly myeloid, with low expression in T and NK cells.

*Summarised from the analysis code and plots; see the scripts for the underlying evidence.*

No `renv.lock` is committed; the key packages are `Seurat`, `dplyr`, `ggplot2` and the helper package [`r-utility-functions`](https://github.com/Eomesodermin/r-utility-functions).

## uTILity version

**The version of the uTILity collection used here was not recorded.** The scripts read the harmonised Seurat objects (`Unity_dataset`, `filtered_seuratObjects_harmony.rds`) from a local copy that was never tied to a Zenodo version, so it cannot be confirmed which release of [Zenodo 17977149](https://zenodo.org/records/17977149) they came from. Treat the cell and study counts above as those of the collection in general, and expect small differences if you re-run against the current release.

## Data

The raw and processed data are not stored in this repository. Download the data from the source above into `data/` (git-ignored) before running the scripts; processed objects are regenerated by the numbered scripts.
