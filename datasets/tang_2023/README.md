## What this analysis does

Scores a CD160-positive NK signature and DGAT expression across cancer types, tissues and NK subsets.

## Key finding

The CD160-positive signature marks a tissue- and tumour-resident NK state and is low in blood NK cells; DGAT1 and DGAT2 are expressed in a restricted subset of NK states and vary by cancer type.

*Summarised from the analysis code and plots; see the scripts for the underlying evidence.*

## Scripts

No `renv.lock` is committed; the key packages are `Seurat`, `dplyr`, `ggplot2` and the helper package [`r-utility-functions`](https://github.com/Eomesodermin/r-utility-functions).

## Data

The raw and processed data are not stored in this repository. Download the data from the source above into `data/` (git-ignored) before running the scripts; processed objects are regenerated by the numbered scripts.
